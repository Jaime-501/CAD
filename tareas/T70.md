para que el rediseño comparta una única fuente de verdad. No se usan todavía en

## `ui_tokens.md`
Tabla token → valor → uso previsto; breakpoints oficiales **480, 768, 1024** (las
variables CSS no valen dentro de `@media`: van como números documentados); y la regla:
«desde T72b, ningún componente escribe colores, radios ni sombras literales».
Incluye la tabla de contraste generada por `contraste.mjs`.

## `contraste.mjs`
Script Node sin dependencias que calcula la relación de contraste WCAG de:
`--text-1..4` sobre `--bg-0`; `--brand-400` sobre `--bg-0`; `--on-brand` sobre
`--brand-500`; `--danger` sobre `--bg-0`. Marca AA (≥ 4.5:1 texto normal) sí/no.
Pega la tabla en `ui_tokens.md`. Si `--text-3` o `--brand-400` NO pasan AA,
repórtalo (no cambies el valor).
