# T70 — Tokens de diseño en `style.css`

## Objetivo
Definir el sistema de tokens CSS (sin usarlos aún en componentes) para que todo
el rediseño comparta color, radio, sombra, desenfoque, movimiento y z-index.

## Depende de
T69 (`docs/investigacion/ui_base.md`: léelo, sobre todo las variables que ya
existan en `style.css`).

## Puedes tocar
- `frontend/src/style.css` (solo AÑADIR el bloque de tokens)
- `docs/firmas/` no aplica; documenta en `docs/investigacion/ui_tokens.md` (nuevo)
- `PROGRESO.md`

## NO debes tocar
Componentes `.svelte`, `*.go`, `frontend/wailsjs/**`, `index.html`.

## Tokens (nombres obligatorios; valores en `ui_tokens.md` de Stitch)
Bloque `:root` ordenado y comentado:
- Fondos: `--bg-0:#090d16`, `--bg-1:#0f172a`, `--bg-2:#1e293b`.
- Superficies: `--surface-glass`, `--surface-card`, `--surface-panel`,
  `--surface-input`, `--surface-chip`, `--surface-chip-hover`.
- Bordes: `--border-subtle`, `--border`, `--border-strong`, `--border-accent`.
- Texto: `--text-1..4` (`--text-4` solo decorativo; documéntalo en el comentario).
- Marca: `--brand-400/500/600`, `--brand-glow`, `--brand-teal`, `--on-brand`,
  `--grad-brand` (90°, 500→teal), `--grad-chip-active` (135°).
- Semánticos: `--info`, `--alert`, `--fav`, `--indigo`.
- Radios: `--r-sm:6px`, `--r-md:12px`, `--r-lg:16px`, `--r-xl:24px`, `--r-full`.
- Sombras: `--sh-card`, `--sh-panel`, `--sh-glow`, `--sh-card-hover`, `--sh-player`.
- Marco de póster: `--frame-poster` (degradado vertical blanco .20→.05→.10).
- Blur: `--blur-sm:10px`, `--blur-md:14px`, `--blur-lg:28px`; dentro de
  `@media (max-width:767px)` `--blur-lg` = `14px`.
- Movimiento: `--ease-out`, `--ease-std`, `--dur-fast:150ms`, `--dur:250ms`,
  `--dur-slow:350ms`.
- Espacio (escala de 4 px): `--sp-1` … `--sp-8`.
- Capas: `--z-base:0`, `--z-sticky:20`, `--z-bar:30`, `--z-drawer:40`, `--z-toast:50`.
- Si `style.css` ya tenía variables con valor equivalente, conserva el nombre
  viejo como alias (`--viejo: var(--nuevo)`); si el valor difiere, NO lo cambies
  y repórtalo.

## Documentar (`ui_tokens.md`)
Tabla token → valor → uso, los breakpoints oficiales (480, 768, 1024; las CSS
vars no valen en `@media`, así que van como números documentados) y la regla:
«desde T73, ningún componente nuevo escribe colores, radios ni sombras literales».
