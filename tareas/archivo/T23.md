> Ejecuta SOLO esta tarea. Si necesitas tocar un archivo fuera de "Puedes tocar", detente y repórtalo.

**Depende de:** T20, T21, T22

**Objetivo:** Actualizar tipos y métodos expuestos **una sola vez**, después del último cambio de API en Go.

**Puedes tocar:** `frontend/wailsjs/**` (solo generación automática), `PROGRESO.md`, `docs/BITACORA.md`

**NO debes tocar:** el resto del frontend manual, ni el código Go.

**Pasos:**
- Ejecutar `docker compose run --rm app wails generate module`.
- Comprobar que existen los métodos `SearchAnime`, `GetAnimeDetails`, `GetVideoSources`, `SaveProgress`, `GetProgress`.
- Comprobar que existen los tipos usados por esas firmas: `DetalleResultado`, `WatchProgress`, `VideoSource`, `Subtitle` (y los modelos que cuelgan de ellos, p. ej. `Anime`, `Episode`).

- Anotar en `PROGRESO.md` los nombres exactos de campos generados (snake_case) para T24–T27.

**Comprobación:**
