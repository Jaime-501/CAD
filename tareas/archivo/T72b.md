# T72b — Puente de color: literales a tokens

Serie v1.4.0, rama `feature/rediseno-movil`. Pasada MECÁNICA: solo color, sombra y
radio. Prohibido cambiar layout, estructura, markup o lógica.

## Objetivo
Sustituir en los componentes existentes los colores hex/rgba literales y las variables
`--cad-*` por los tokens de T70, para que toda la app use una sola paleta (verde de
Stitch) antes de rediseñar vistas.

## Depende de
T70, T71, T72. Lee `docs/investigacion/ui_base.md` §2–§3 y `ui_tokens.md`.

## Puedes tocar
Los `.svelte` existentes (solo dentro de `<style>`), `frontend/src/style.css` (solo para
mapear: NO borres `--cad-*`, déjalas definidas pero sin uso),
`docs/investigacion/ui/verificar_ui.mjs`, `docs/investigacion/ui_mapeo_color.md` (nuevo),
`PROGRESO.md`.

## NO debes tocar
`<script>` ni markup de ningún componente, `*.ts`, `*.go`, `wailsjs/**`, los 6
componentes de T72, `index.html`, tamaños, márgenes, paddings, `display`, `grid`, `flex`.

## Pasos
1. Antes de editar, genera `ui_mapeo_color.md` con TODA la lista de literales de color por
   archivo y línea (script o grep) y su token asignado. Mapeo base (confírmalo mirando el
   uso real; ante duda, el más cercano en luminosidad y dilo en la tabla):
   - `#151515` → `--bg-0`
   - `#1e1e24`, `#111` → `--surface-card` (superficies) o `--bg-1`/`--bg-0` (fondos)
   - `#2a2a35` → `--surface-chip` (chips, botones) o `--bg-2` (bloques)
   - `#3f3f46` → `--border-strong`; bordes de 1 px → `--border`
   - `#a1a1aa` → `--text-3`; `#ffffff`/`#fff` → `--text-1`
   - `#4ade80` → `--brand-400` en texto/iconos/bordes, `--brand-500` en rellenos
   - texto sobre relleno verde (`#111`/`#000`) → `--on-brand`
   - `#f87171` → `--danger`
   - `rgba(...)` de sombras y overlays → el token de sombra/superficie más próximo; los
     scrims negros de degradado (`rgba(0,0,0,x)`) pueden quedarse literales y se listan
     como excepción justificada.
   - `var(--cad-radio)` y `8px` de radio → `--r-md`; radios pequeños (≤ 6px) → `--r-sm`;
     tarjetas grandes (≥ 14px) → `--r-lg`; círculos → `--r-full`.
2. Aplica el mapeo archivo por archivo. NO cambies ningún valor de tamaño o espacio.
3. Ejecuta la comprobación de geometría de T69 (`medir_ui.mjs`/`verificar_ui.mjs`): las
   cajas de tarjeta de episodio (170,39), tarjeta de Home (263,8), pestañas, botones y la
   rejilla (columnas) NO pueden variar. Cualquier diferencia > 1 px, repórtala.
4. Captura antes/después de las vistas de T69 a 360 y 1280 px y compáralas: deben diferir
   SOLO en color. Adjunta un resumen (píxeles distintos por vista).

## Criterios de aceptación
- `grep -rnE "#[0-9a-fA-F]{3,8}\b" frontend/src/*.svelte` → solo excepciones listadas en
  `ui_mapeo_color.md` (idealmente 0).
- `grep -rn "\-\-cad-" frontend/src/*.svelte` → 0 usos.
- `git diff` de cada `.svelte` toca únicamente líneas dentro de `<style>` (adjunta el
  comando y el resultado que lo demuestre).
- Geometría sin cambios (> 1 px reportado); `overflowH = 0` a 360 px.
- `npm run check` 0/0, `npm run build` OK, tests `.ts` verdes, `grep wailsjs` solo
  `api.ts`, Go intacto (435).
