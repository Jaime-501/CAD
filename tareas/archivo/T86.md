## Especificación
1. **Tokens**: añade `--scrim` y `--scrim-strong` y sustituye `rgba(0, 0, 0, 0.75)` (velo del
   cajón) y `rgba(0, 0, 0, 0.65)` (overlay de carga). Tras esto, `grep` de `#hex|rgba(` en
   `*.svelte` debe dar 0 resultados (los comentarios con `rgba(` se reescriben).
2. **Home**: `.error-proveedor` → `EstadoVista variante="error"` compacto (título "No se pudo
   cargar {proveedor}", texto = el error) y `Btn` secundario "Reintentar" (44 px en
   `max-width: 899px`). Sin ocupar más alto que el bloque actual + 24 px; reporta ambos.
   El esqueleto `.fila-fantasma` se mantiene (ya usa tokens); no cambies sus medidas.
3. **Detalle**: `.error` → `EstadoVista error`; `.estado` ("Cargando detalle…", "Sin detalle",

   episodios…") se queda como línea de texto en `--fs-sm` y `--text-3` con `aria-live`.
4. **Reproductor**: `.error-caja` → `EstadoVista error` + `Btn` "Reintentar" (llama a la misma
   función `reintentar`); `.aviso` se mantiene.
5. **Cajón**: error → `EstadoVista error` + `Btn` "Reintentar" (`cargarHistorial`); vacío →
   `EstadoVista vacio` ("Aún no hay nada que retomar."); el esqueleto del historial usa

   pie y papeleras NO cambian (T73).
6. **Barrido de px (SOLO `<style>`)**: tokeniza únicamente cuando el valor es IDÉNTICO:
   - espaciado: 4→`--sp-1`, 8→`--sp-2`, 12→`--sp-3`, 16→`--sp-4`, 20→`--sp-5`, 24→`--sp-6`,
