episodio siguiente a uno dado. El frontend no calcula nada de esto.

## `episodiosCompletos` (contrato exacto)
```go
var (
    intervaloEsperaEpisodios = 50 * time.Millisecond // variable para que los tests la reduzcan
    esperaMaximaEpisodios    = 60 * time.Second
)

// episodiosCompletos devuelve el detalle y la lista COMPLETA de episodios. Nunca devuelve una lista parcial.
func (n *Nucleo) episodiosCompletos(ctx context.Context, proveedor, animeID string) (models.AnimeDetail, []models.Episode, error)
```
1. `proveedor` y `animeID` se normalizan con `strings.TrimSpace`; `clave := cache.Clave(proveedor, animeID)`.
2. `res, err := n.Detalle(ctx, proveedor, animeID)`, pasando el `ctx` **recibido tal cual**: no uses un contexto derivado con
   timeout ni con `cancel`, porque el contexto del stream nace del que se pasa a `Detalle` (`iniciarStream`), y cancelarlo
   mataría los lotes que el frontend necesita después. Si `err != nil`, devuélvelo sin envolverlo de nuevo.
3. Si el proveedor (`n.proveedor(proveedor)`) **no** implementa `scraper.EpisodeStreamer`: `Detalle` ya devolvió la lista
   completa y síncrona (no se cachea) ⇒ devuelve `res.Detail` y `res.Episodes`.
4. Si lo implementa: espera a que `n.cacheLocal.Get(clave)` devuelva una entrada con `Complete == true`. Comprueba
   **antes** del primer tick y luego cada `intervaloEsperaEpisodios`. Desenlaces:
   - entrada completa ⇒ devuelve **copias** de `e.Detail` y `e.Episodes`;
   - entrada ausente (el stream falló, otro anime lo canceló o caducó) ⇒ error en español sin lista parcial
     («no se pudo completar la lista de episodios»);
   - `ctx.Done()` ⇒ error que cumple `errors.Is(err, ctx.Err())`;
   - pasan `esperaMaximaEpisodios` ⇒ error en español (el temporizador solo gobierna la espera, no el contexto de `Detalle`).
5. No leas ni uses `st.fallo` ni los internos del stream: la señal es solo la caché.

## Resto de decisiones fijas
- `ErrSinHistorial` (nuevo, exportado, español): no hay registros para ese (proveedor, anime).
- **Número del episodio actual** = el de `models.ParseEpisodeID(record.EpisodeID)` (canónico; película ⇒ 0). No usar `record.EpisodeNumber`.
- `siguienteDe(episodes []models.Episode, actual int) (models.Episode, bool)`: el de **menor `Number` estrictamente mayor**
  que `actual`; no depende del orden de entrada ni asume números consecutivos; ignora episodios de kind `movie`.
- `estaEnEmision(status string) bool`: normaliza (minúsculas, sin acentos, `strings.TrimSpace`) y devuelve `true` **solo** si el
  resultado es exactamente `en emision`. Cubre `En emision` (JKAnime) y `En emisión` (AnimeAV1). Todo lo demás
  (`Concluido`, `Finalizado`, `Por estrenar`, `Próximamente`, `Desconocido`, vacío) ⇒ `false`. Prohibido añadir valores no observados.
- `Retomar(ctx, provider, animeID)`:
  1. último registro del par desde `LastPerAnime` (sin él ⇒ `ErrSinHistorial`; sin almacén ⇒ `ErrHistorialNoDisponible`);
  2. `!IsWatched` ⇒ `ResumeInfo{Action: resume, EpisodeID: record.EpisodeID, EpisodeNumber: número parseado, StartAt: record.CurrentTime}`
     **sin pedir episodios** (no llama a `Detalle`);
  3. `IsWatched` y kind película ⇒ `completed`, sin pedir episodios;
  4. `IsWatched` y serie ⇒ `episodiosCompletos` y `siguienteDe`: encontrado ⇒ `next` con `StartAt: 0`; no encontrado ⇒
     `up_to_date` si `estaEnEmision(detalle.Status)`, si no `completed`. Si `episodiosCompletos` falla ⇒ devuelve ese error
     (la UI lo muestra como «No se pudo retomar»); nunca decidas `completed`/`up_to_date` con una lista no completa.
- `SiguienteEpisodio(ctx, provider, animeID, episodeID)`: parsea `episodeID`; película ⇒ `NextEpisode{Found:false}` sin pedir
  episodios; si no, `episodiosCompletos` y `siguienteDe` ⇒ `Found:true`, `EpisodeID`, `Number`; sin siguiente ⇒ `Found:false`.
  Si `episodiosCompletos` falla ⇒ devuelve el error (la UI oculta el botón). Proveedor desconocido ⇒ el mismo error que `Detalle`.
- Los enlaces de vídeo no se tocan ni se cachean.
- `app.go`: `ResumeAnime(provider, animeID string) (models.ResumeInfo, error)` y
  `GetNextEpisode(provider, animeID, episodeID string) (models.NextEpisode, error)`; solo delegan con `a.contexto()`.
