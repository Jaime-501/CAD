# T06 — JKAnime — resolver de excepciones

> Antes de empezar lee: `AGENTS.md`, `tareas/00_REGLAS.md` y `PROGRESO.md`.
> Usa las **firmas reales** registradas en `PROGRESO.md`, no las del plan.
> Ejecuta SOLO esta tarea. Si necesitas tocar un archivo fuera de "Puedes tocar", detente y repórtalo.

**Depende de:** T02

**Objetivo:** Mecanismo de excepciones para títulos cuya URL normal no basta.

**Puedes tocar:** `internal/scraper/jkanime/exceptions.go`, `internal/scraper/jkanime/exceptions_test.go`, `internal/scraper/jkanime/testdata/`

**NO debes tocar:** `frontend/**`, `app.go`

**Pasos:**
- Resolver que descarga el mapa remoto de excepciones usando `httpx.HTTPDoer`.
- Timeout corto y caché en memoria durante la ejecución (protegida con mutex).
- **Límite de tamaño** de la respuesta (ej. 1 MB) y validación de esquema: descartar entradas con URL no HTTP/HTTPS o claves vacías.
- Si el recurso remoto falla, continuar sin excepciones (sin bloquear la app).
- Tipo `ResolvedAnimeURL{URL string, UsedException bool}`.

**Entregable:** `ExceptionResolver` con `Resolve(ctx, slug) ResolvedAnimeURL`.

**Comprobación:**
- Fixture de excepciones.
- Tests: URL normal, URL sustituida, mapa remoto caído, respuesta demasiado grande, JSON inválido.
- `go test -race ./...` 🔒
