TAREA T61 — Conectar el resolver de MP4Upload a JKAnime y AnimeAV1.

OBJETIVO
Cuando un episodio ofrece MP4Upload como iframe (var servers en JKAnime; embeds en
AnimeAV1), publicar ADEMÁS una fuente mp4 directa resuelta con internal/scraper/embeds,
manteniendo el iframe original como respaldo. SelectBestSource ya prefiere MP4 > iframe.

PUEDES TOCAR
- internal/scraper/jkanime/** y internal/scraper/jkanime/extractors/** (solo lo
  necesario para invocar embeds desde la cadena de fuentes)
- internal/scraper/animeav1/** (solo sources.go y sus tests)
- internal/app/**  solo tests E2E/fakes y el cableado mínimo de la inyección del doer
- docs/firmas/{jkanime,animeav1,extractors,app}.md, PROGRESO.md
NO debes tocar: embeds/** (si necesita cambios, DETENTE y repórtalo), stream/**,
frontend/**, app.go, main.go, models/**.

REQUISITOS
1. Un fallo del resolver NUNCA rompe el resto: si Resolve falla (embed borrado, 4xx,
   timeout), se registra un slog.Warn sin URL y se conserva el iframe y las demás
   fuentes. Timeout propio corto para la resolución (p. ej. 8 s) y ctx respetado.
2. JKAnime: tras extraer var servers, por cada iframe que embeds.CanHandle reconozca,
   resolver y añadir la fuente mp4. Dedup: no duplicar si ya existe el mismo recurso.
3. AnimeAV1: igual sobre embeds SUB y DUB, conservando el campo Language de cada una
   (SUB y DUB siguen siendo fuentes distintas). animeav1 NO importa jkanime ni
   extractors; solo embeds.
4. Referer: la VideoSource resuelta lleva el Referer del embed; comprueba que el proxy
   (Register) lo guarda en la sesión y NO lo envía al frontend (contrato T29).
5. El proxy de streaming debe aceptar el host del CDN (a2.mp4upload.com:183, puerto no
   estándar). Verifica con un test que el anti-SSRF no lo bloquea por el puerto y que
   Range devuelve 206. Si stream necesita un cambio, DETENTE y repórtalo.
6. LOGS: añade a los E2E (o amplía comprobarLogsSinSecretos) una comprobación de que el
   path /d/<token>/ de la URL del CDN no aparece en ningún log. Si aparece, DETENTE y
   repórtalo: habrá que ampliar logx.Redact en una tarea propia.
7. El E2E offline exige peticiones exactas: actualízalo para incluir la petición al
   embed de MP4Upload en el sitio falso (fixture testdata/mp4upload_embed.html ya
   existente) y, para AnimeAV1, un servidor falso equivalente. Mismas garantías de
   "nada sale a la red". Declara como artificial cualquier HTML que no sea fixture real.
8. Mide y reporta (sin cambiar comportamiento): en las muestras disponibles, cuántos
   episodios tenían MP4Upload y cuántos quedaron con mp4 resuelto en la fuente elegida
   por SelectBestSource.
9. No se cachea ninguna URL resuelta (regla 9).

COMPUERTA
gofmt -l . · go vet ./... y -tags integration · go build ./... ·
go test -race -count=1 ./... · go test -tags integration ./... -run "E2E|MP4Upload" -v
· npm run check. Recuento de --- PASS antes (420) y después.
