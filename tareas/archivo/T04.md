**Objetivo:** Formalizar la interfaz multi-proveedor con `context.Context` y definir el mecanismo de streaming de episodios.

**Puedes tocar:** `internal/scraper/provider.go`, `internal/scraper/registry.go`, `internal/scraper/*_test.go`

**NO debes tocar:** `frontend/**`, `app.go`, `internal/models/**`

**Pasos:**
- Interfaz base:
  ```go
  type Provider interface {
      Name() string
      Search(ctx context.Context, query string) ([]models.Anime, error)
      GetAnimeDetails(ctx context.Context, id string) (models.AnimeDetail, []models.Episode, error)
      GetVideoSources(ctx context.Context, episodeID string, opts SourceOpts) ([]models.VideoSource, error)
  }
  ```
- `SourceOpts{ NoCache bool }` (usado por el reproductor para pedir una fuente nueva tras un error fatal).
- Interfaz opcional de streaming:
  ```go
  type EpisodeStreamer interface {
      // Devuelve el detalle y la primera página; el resto se emite por onBatch
      // hasta completar, error o cancelación de ctx.
      StreamAnimeDetails(ctx context.Context, id string,
          onBatch func(models.EpisodeBatch)) (models.AnimeDetail, []models.Episode, error)
  }
  ```
- Registro: `Registry` con `Register(Provider)`, `Get(name)`, `All()` (seguro para concurrencia).
- `GetAnimeDetails` sobre providers sin detalles devuelve un error descriptivo (`ErrNoDetails`).
- **No** incluir aquí el assert `var _ Provider = (*JkAnime)(nil)`; va en T07.

**Entregable:** `Provider`, `EpisodeStreamer`, `SourceOpts`, `Registry`, `ErrNoDetails`.

**Comprobación:**

- Test del registro con un provider falso.
