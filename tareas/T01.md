# T01 — Logging y observabilidad base

> Antes de empezar lee: `AGENTS.md`, `tareas/00_REGLAS.md` y `PROGRESO.md`.
> Usa las **firmas reales** registradas en `PROGRESO.md`, no las del plan.
> Ejecuta SOLO esta tarea. Si necesitas tocar un archivo fuera de "Puedes tocar", detente y repórtalo.

**Depende de:** —

**Objetivo:** Tener logging estructurado con redacción de secretos desde el inicio, para no reescribir el código al final.

**Puedes tocar:** `internal/logx/**`

**NO debes tocar:** `frontend/**`, `app.go`, `internal/models/**`

**Pasos:**
- Crear `internal/logx/logx.go` con un `*slog.Logger` configurable (nivel debug solo en modo desarrollo).
- Implementar un `slog.Handler` envolvente o función `Redact` que enmascare: `Cookie`, `Set-Cookie`, `Authorization`, parámetros `csrf`/`token`/`_token` en URLs y cuerpos.
- Exponer helpers: `logx.Request(provider, op, url, status, dur, extractor)`.

**Entregable:** `logx.New(dev bool) *slog.Logger`, `logx.Redact(string) string`, `logx.Request(...)`.

**Comprobación:**
- `go vet ./...`
- Tests: una cadena con cookie y CSRF sale enmascarada; una URL con `?token=abc` sale con `?token=***`.
