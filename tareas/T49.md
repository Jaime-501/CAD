## `historial.ts` (API fija)
```ts
export const historial: Writable<models.WatchProgress[]>        // vacío al inicio
export const historialEstado: Writable<'idle'|'loading'|'ready'|'error'>
export async function cargarHistorial(): Promise<void>          // llama a getRecentProgress(); en error: estado 'error' y deja la lista anterior
export const PROVEEDORES_ORDEN = ['jkanime', 'animeav1'] as const
export const NOMBRE_PROVEEDOR: Record<string,string> = { jkanime: 'JKAnime', animeav1: 'AnimeAV1' }
export function proveedorDe(p: models.WatchProgress): string    // p.provider || prefijo de p.episode_id antes del primer ':' || ''
export function agruparPorProveedor(items): { provider: string; nombre: string; items: models.WatchProgress[] }[]
   // orden: primero PROVEEDORES_ORDEN (solo los que tengan items), luego proveedores desconocidos por nombre; dentro de cada grupo se CONSERVA el orden recibido (ya viene por recencia desde Go)
export function formatearTiempo(seg: number): string            // 'm:ss' (<1 h) o 'h:mm:ss'; negativos/NaN → '0:00'
export function numeroDeEpisodio(p): string                     // 'Ep N' (N de p.episode_number si >0; si no, regex /:(?:episode|special):(\d+)$/ sobre episode_id); 'Película' si episode_id termina en ':movie'; '' si nada
export function tituloVisible(p): string                        // p.anime_title || slug (p.anime_id) con '-' → ' ' y primera letra en mayúscula
export function fraccionProgreso(p): number                     // is_watched ? 1 : clamp(current_time/total_duration, 0, 1); total ≤ 0 → 0
```
Refresco: `cargarHistorial()` en el montaje de `App.svelte` y cada vez que la vista activa **deja** de ser el reproductor.

## `TarjetaHistorial.svelte`
- Props: `item: models.WatchProgress`, `onOpen: (item: models.WatchProgress) => void`, `resolviendo?: boolean`, `mensaje?: string` (los usa T50; aquí quedan declarados y se pintan si vienen).
- Elemento raíz `<button type="button">` que ocupa todo el ancho; al hacer clic llama a `onOpen(item)`. Desactivado si `resolviendo`.
- Contenido: portada 48×68 px (`object-fit:cover`, `loading="lazy"`, `alt=""`; si falta `cover_url` o falla la carga, bloque de reemplazo con la inicial del título); a la derecha: título (máx. 2 líneas con elipsis), línea secundaria `numeroDeEpisodio · formatearTiempo(current_time)` (si `is_watched`: `numeroDeEpisodio · Visto ✓`), y debajo barra de progreso de 4 px de alto (ancho = `fraccionProgreso*100%`, color de acento existente, `role="progressbar"` con `aria-valuenow`).
- Si `mensaje`, se muestra bajo la barra en texto pequeño (`aria-live="polite"`).
- Estados: hover y foco visibles con variables existentes.

## `BarraLateral.svelte`
- Renderiza `agruparPorProveedor($historial)`. Cada grupo: `<section aria-label="Historial de {nombre}">` con encabezado (nombre + contador) y sus tarjetas.
- Vacío (`historialEstado === 'ready'` y 0 items): "Aún no hay nada que retomar."; cargando por primera vez: 3 tarjetas fantasma (skeleton) sin animación si `prefers-reduced-motion`; error: "No se pudo cargar el historial." + botón "Reintentar" (`cargarHistorial()`).
- Prop nueva `onOpen` que se pasa a cada tarjeta (por defecto función vacía).
- La barra contraída (56 px) oculta el contenido (solo botón de expandir).
