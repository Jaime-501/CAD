TAREA T60 — Resolver de MP4Upload en un paquete neutro (sin cableado).

CONTEXTO
El informe de adds clasificó MP4Upload como el único host RESOLVIBLE limpio: la URL
del MP4 sale en claro del HTML del embed y el CDN responde 206 a Range sin comprobar
Referer. MP4Upload aparece en ambos proveedores (var servers de JKAnime y embeds de
AnimeAV1). Como animeav1 no puede importar jkanime ni extractors (00_REGLAS.md),
crea un paquete neutro que ambos puedan consumir después:

  internal/scraper/embeds/        paquete `embeds`
    embeds.go        interfaz Resolver:
                       Name() string
                       CanHandle(url string) bool
                       Resolve(ctx, url, referer string) ([]models.VideoSource, error)
    mp4upload.go     resolver de MP4Upload
    mp4upload_test.go, embeds_test.go, embeds_integration_test.go
    testdata/

Dependencias permitidas: models, httpx, logx. NO importa scraper/jkanime,
extractors ni animeav1.
