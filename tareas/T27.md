# T27 — Reproductor multi-recurso (sincronización y softsubs)

> Antes de empezar lee: `AGENTS.md`, `tareas/00_REGLAS.md`, `PROGRESO.md` y `docs/firmas/app.md`, `docs/firmas/models.md` y `docs/firmas/stream.md`.
> Usa las **firmas reales** (nombres exactos de `VideoSource`, `ResourceType`, `Subtitle`, `WatchProgress`) registradas en `PROGRESO.md` y `docs/firmas/`, no las del plan.
> Ejecuta SOLO esta tarea. Si necesitas tocar un archivo fuera de "Puedes tocar", detente y repórtalo.

**Depende de:** T19, T24, T25 (vista placeholder del reproductor)

**Objetivo:** Reproducir vídeo, inyectar subtítulos y reportar progreso.

**Puedes tocar:** componente del reproductor en `frontend/src/` (sustituye el placeholder de T25), `frontend/package.json` y `frontend/package-lock.json` (solo para añadir `hls.js`), `PROGRESO.md`, `docs/BITACORA.md`

**NO debes tocar:** `app.go`, `frontend/wailsjs/**`

**Pasos:**
- Pedir fuentes con `GetVideoSources(provider, episodeID, false)`; la primera es la preferida.
- `ResourceType=HLS` → `hls.js` (WebView2/Chromium no reproduce HLS nativo; usa el nativo solo si `canPlayType` lo soporta); `MP4` → `<video src>`; **`Iframe` → `<iframe>` embebido, sin control de progreso** y con aviso en la UI (`referrerpolicy="no-referrer"`).
- Selector manual de servidor/calidad con las fuentes restantes.
- Subtítulos: inyectar `Subtitles` vía `<track>` (las URLs ya pasan por el proxy). El `<video>` necesita `crossorigin="anonymous"` porque el origen de la página y el del proxy (`127.0.0.1:<puerto>`) son distintos; el proxy ya envía CORS.
- Progreso: *throttle* ~5 s en `timeupdate` hacia `SaveProgress`; además guardar en `pause`, `ended`, `beforeunload` y al desmontar.
- Al cargar: recuperar el tiempo guardado y fijar `currentTime` (no restaurar si el episodio ya estaba `IsWatched`; reiniciar desde 0).
- Error fatal (`Hls.Events.ERROR`, fatal) o error de `<video>`: limpiar intervalo/instancia, llamar `GetVideoSources(..., noCache=true)`, probar la siguiente fuente y, si se agotan, mostrar error con botón "Reintentar".
- Destruir `hls.js` y listeners al desmontar.

**Nota sobre la comprobación manual (importante):** el proxy escucha en `127.0.0.1:<puerto aleatorio>` **dentro del contenedor**. Con `docker compose up`, el navegador del host (http://localhost:34115) no puede alcanzar ese puerto, así que la reproducción real no se puede verificar en ese flujo. Para la prueba manual, compila el ejecutable de Windows desde Docker (`docker compose run --rm app wails build -platform windows/amd64`) y ejecútalo en Windows 11 (WebView2). En el flujo Docker solo se verifican tipos, estados y la UI sin reproducción real. Anota en `PROGRESO.md` cuál de las dos pruebas se hizo.

**Comprobación:**
- `npm run check` (desde `frontend/`).
- Manual (con el `.exe` de Windows): reproducción HLS y MP4; subtítulos visibles; el tiempo se conserva al volver atrás; recuperación ante fuente caída; iframe sin romper la UI.
