## Decisiones fijas
- API exacta de `v1.2_PLAN.md`: `Favorites`, `OpenFavorites(dir)`, `Add`, `Remove`, `Has`, `List`.
- Archivo `favoritos.json` = array JSON de `models.Favorite`, indentado, escrito a temporal + `rename`.
- `dir == ""` → `ErrDirectorioVacio` (el error ya existe en el paquete). Crea el directorio si no existe (`MkdirAll`), igual que el historial.
- Archivo corrupto (JSON inválido) → se renombra a `favoritos.json.bak` y se arranca vacío, sin error.
- `Add`: `Provider` y `AnimeID` no vacíos (si no, error con mensaje en español). Si `AddedAt == 0` → `now().Unix()` con reloj inyectable `now` no exportado (por defecto `time.Now`). Si ya existe (misma `Key()`): devuelve `(false, nil)`, conserva `AddedAt`, actualiza `Title` y `CoverURL` y persiste.
- `Remove`: `(true,nil)` si existía, `(false,nil)` si no (no reescribe el archivo en este caso).
- `List`: slice **no nil**, copias, orden `AddedAt` desc, desempate por `Key()` asc.
- Seguro para concurrencia (`sync.Mutex`).
