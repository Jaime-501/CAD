# T19 — Proxy local de streaming (NUEVA)

> Antes de empezar lee: `AGENTS.md`, `tareas/00_REGLAS.md` y `PROGRESO.md`.
> Usa las **firmas reales** registradas en `PROGRESO.md`, no las del plan.
> Ejecuta SOLO esta tarea. Si necesitas tocar un archivo fuera de "Puedes tocar", detente y repórtalo.

**Depende de:** T02, T03

**Objetivo:** Permitir que `<video>`/`hls.js` reproduzcan fuentes que exigen `Referer`/headers personalizados o que bloquean por CORS.

**Puedes tocar:** `internal/stream/**`

**NO debes tocar:** `frontend/**`, `app.go`

**Pasos:**
- Implementar un `http.Handler` (montable como `AssetServer.Handler` de Wails o como servidor en `127.0.0.1:<puerto aleatorio>`).
- Ruta: `/proxy?s=<sessionID>&u=<url-codificada>`. Las cabeceras requeridas (`Referer`, `Headers` del `VideoSource`) se asocian a un `sessionID` en memoria (con TTL), nunca se pasan por la URL.
- Reenviar la petición con `httpx` inyectando headers y cookies; soportar **`Range`** (206) para MP4.
- Para `.m3u8`: reescribir URIs de segmentos, claves (`#EXT-X-KEY`) y sub-playlists para que vuelvan a pasar por el proxy.
- Para `.vtt`: proxy con `Content-Type: text/vtt` y cabeceras CORS.
- Seguridad: escuchar solo en loopback; validar que `u` sea HTTP/HTTPS; rechazar IPs privadas/loopback como destino (anti-SSRF); límite de sesiones.
- API Go: `Register(source models.VideoSource) (proxiedSource models.VideoSource)`, que devuelve la fuente con URLs ya apuntando al proxy.
- Cancelar la petición upstream si el cliente cierra la conexión.

**Entregable:** `stream.NewProxy(doer)`, `Handler()`, `Register(...)`.

**Comprobación:**
- `go test -race ./...` 🔒
- Tests con `httptest.Server` upstream: se inyecta Referer; `Range` devuelve 206; manifiesto reescrito; destino privado rechazado; sesión expirada → 404.
