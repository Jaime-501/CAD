## Contrato de ventana.ts (exportar exactamente estos nombres)

Constantes:
- FILAS_INICIAL = 5
- FILAS_TRAMO = 4
- COLUMNAS_POR_DEFECTO = 4
- RETARDO_POR_COLUMNA_MS = 50
- RETARDO_MAXIMO_MS = 300

Funciones puras:
- normalizarColumnas(n: number): number
  Entero >= 1; si n no es finito, es < 1 o es NaN, devuelve COLUMNAS_POR_DEFECTO;
  si no es entero, se trunca (Math.floor).
- tamanoInicial(total: number, columnas: number): number
  min(total, FILAS_INICIAL * columnas normalizadas); total <= 0 o inválido => 0.
- siguienteTamano(actual: number, total: number, columnas: number): number
  Objetivo = actual + FILAS_TRAMO * columnas; se redondea HACIA ARRIBA al múltiplo de
  columnas y se limita a total. Si actual >= total devuelve total. Nunca devuelve
  menos que min(actual, total). total <= 0 => 0.
- cubrirIndice(actual: number, indice: number, total: number, columnas: number): number
  Tamaño mínimo (múltiplo de columnas, limitado a total) que incluye la posición
  `indice` (base 0). Nunca reduce: devuelve >= min(actual, total). indice < 0 se
  trata como 0; indice >= total devuelve total.
- retardoEntrada(indice: number, columnas: number): number
  min((indice % columnas) * RETARDO_POR_COLUMNA_MS, RETARDO_MAXIMO_MS), con columnas
  normalizadas e indice < 0 tratado como 0.
- claveVentana(provider: string, animeID: string): string
  `${provider}:${animeID}`.

Memoria por sesión (mismo patrón que scrollPorClave de views.ts: un Map a nivel de
módulo, sin stores de Svelte):
- recordarVisibles(clave: string, n: number): void  (ignora n no finito o < 0)
- recuperarVisibles(clave: string): number | undefined
- olvidarVisibles(clave: string): void

Todas las entradas inválidas (NaN, Infinity, negativos) deben devolver un valor
seguro, sin lanzar excepciones.

## Tests (ventana.test.ts)

Ejecutarlos con el mismo mecanismo que frontend/src/etiquetas.test.ts (esbuild de
Vite; copia el comando de la cabecera de ese archivo y ponlo en la cabecera del
nuevo). Mínimo estas comprobaciones, con el resultado numérico esperado calculado a
mano en el propio test:
1. normalizarColumnas: 0, -3, NaN, Infinity, 4.9, 5.
2. tamanoInicial: total 0, total menor que 5 filas, total 366 con 3/4/5 columnas.
3. siguienteTamano: 20 -> 40 con 5 cols; 20 con 3 cols -> 32 (20+12=32, múltiplo de 3 => 33);
   verifica el valor exacto con la regla de redondeo hacia arriba; tope en total;
   actual >= total; total 0.
4. cubrirIndice: índice dentro de lo ya visible (no reduce), índice en el siguiente
   tramo, índice >= total, índice negativo, no-múltiplo de columnas.
5. retardoEntrada: columna 0, 1, 5; índice grande (usa módulo); tope 300 con columnas
   altas (p. ej. 10); índice negativo.
6. Map: recordar/recuperar/olvidar, clave inexistente => undefined, n inválido ignorado.
7. Propiedad: para columnas 3, 4 y 5 y total 366, iterar siguienteTamano desde
   tamanoInicial hasta total: la secuencia es estrictamente creciente, termina en
   exactamente 366 y cada valor intermedio es múltiplo de columnas.
