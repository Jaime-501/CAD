# T26 — Vista de detalle y episodios (UI)

> Antes de empezar lee: `AGENTS.md`, `tareas/00_REGLAS.md` y `PROGRESO.md`.
> Usa las **firmas reales** registradas en `PROGRESO.md`, no las del plan.
> Ejecuta SOLO esta tarea. Si necesitas tocar un archivo fuera de "Puedes tocar", detente y repórtalo.

**Depende de:** T24, T25

**Objetivo:** Mostrar detalle, grid reactivo y marcas de "Visto".

**Puedes tocar:** componentes de detalle en `frontend/src/`

**NO debes tocar:** `app.go`, `frontend/wailsjs/**`

**Pasos:**
- Portada, título, sinopsis, metadatos.
- Grid de episodios con `content-visibility` para rendimiento.
- Estado "Visto" o barra de progreso por tarjeta (desde `progressMap`).
- Indicador "Cargando más episodios…" mientras `episodesComplete=false`; mensaje de aviso si `episodes:complete` trae `Err`.
- Inserción suave al recibir `episodes:update`.
- Acción "Continuar" que abre el último episodio con progreso.

**Comprobación:**
- `npm run check` y revisión visual de la inserción dinámica.
