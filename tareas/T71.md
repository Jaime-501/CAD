# T71 — Base global: tipografía, viewport y safe-area

## Objetivo
Dejar la base lista para móvil: fuentes locales (Inter y Outfit), viewport con
safe-area, foco visible y ajustes táctiles globales.

## Depende de
T70.

## Puedes tocar
- `frontend/src/style.css`, `frontend/src/main.ts` (solo para importar fuentes)
- `frontend/index.html` (SOLO el `<meta viewport>`)
- `frontend/package.json` y `package-lock.json` (SOLO para añadir
  `@fontsource-variable/inter` y `@fontsource-variable/outfit`; si no hay red
  para npm, detente y repórtalo, no descargues fuentes de otro modo)
- `PROGRESO.md`

## NO debes tocar
Componentes `.svelte`, `*.go`, `wailsjs/**`. **No quitar** la
`<meta name="referrer" content="no-referrer">` (regla de AGENTS.md).

## Pasos
1. Fuentes: importa solo el subconjunto latino y pesos necesarios. Tokens
   `--font-sans` (Inter) y `--font-display` (Outfit) con *fallbacks* de sistema.
   Verifica que la app sigue sin pedir nada a Google Fonts (revisa red en Playwright).
2. Escala tipográfica como tokens: `--fs-xs:12px`, `--fs-sm:14px`,
   `--fs-md:16px`, `--fs-lg:18px`, `--fs-xl:22px`, `--fs-2xl:28px`, interlineados
   y `--fw-*`. Mínimo absoluto 12 px.
3. `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">`
   y variables `--sat/--sar/--sab/--sal` desde `env(safe-area-inset-*, 0px)`.
4. Base global: `color-scheme: dark`, fondo `--bg-0`, `-webkit-tap-highlight-color: transparent`,
   `touch-action: manipulation` en controles, `overscroll-behavior-y: none`,
   `:focus-visible` con anillo `--brand-400` (2 px + offset) y
   `@media (hover:none)` sin estilos de hover pegajosos.
5. Fondo ambiental como `radial-gradient` en `body` (esmeralda arriba-izquierda,
   índigo abajo-derecha, ambos de baja opacidad). Prohibido `filter: blur` para esto.

## Criterios de aceptación
- La tipografía cambia a Inter/Outfit en toda la app sin romper ningún layout
  (comparar capturas a 360, 768 y 1280 con las de T69; documentar diferencias).
- 0 peticiones a dominios externos de fuentes (log de red de Playwright).
- Sin desborde horizontal nuevo a 360 px respecto a T69.
- `npm run check` 0/0, `npm run build` OK, tests `.ts` verdes, Go intacto (435).

## Al terminar
Resultado real, `PROGRESO.md` actualizado, y detenerte.
