# T71 — Base global: tipografía, viewport, fondo y safe-area

## Objetivo
Dejar la base lista para móvil: fuentes locales Inter y Outfit, viewport con safe-area,
fondo correcto en toda la página (bug del fondo dividido), foco visible y ajustes
táctiles globales.

## Depende de
T70.

## Puedes tocar
- `frontend/src/style.css`, `frontend/src/main.ts` (solo para importar las fuentes)
- `frontend/index.html` (SOLO el `<meta name="viewport">`)
- `frontend/package.json` y `package-lock.json` (SOLO para añadir
  `@fontsource-variable/inter` y `@fontsource-variable/outfit`; si npm no tiene red,
  detente y repórtalo: no descargues fuentes de otra forma)
- `PROGRESO.md`

## NO debes tocar
`.svelte`, `*.go`, `wailsjs/**`, `main.go`. **No quitar**
`<meta name="referrer" content="no-referrer">`. El archivo de Nunito en `assets/` se
deja en su sitio (se retira en T93); solo deja de usarse.

## Pasos
1. **Fuentes**: importa solo el subconjunto **latin** (cubre español). Antes de escribir
   el import, lista los `.css` reales de cada paquete en `node_modules` y usa los del
   subconjunto latin con peso variable. Tokens `--font-sans` (Inter) y `--font-display`
   (Outfit), cada uno con fallbacks de sistema (`system-ui, -apple-system, "Segoe UI",
   sans-serif`). Sustituye el uso de Nunito en `body`. Los títulos de anime con kanji
   caen al fallback del sistema: es correcto.
2. **Escala tipográfica** como tokens: `--fs-xs:12px` · `--fs-sm:14px` · `--fs-md:16px` ·
   `--fs-lg:18px` · `--fs-xl:22px` · `--fs-2xl:28px`; `--lh-tight:1.2` · `--lh:1.5`;
   `--fw-regular:400` · `--fw-medium:500` · `--fw-semibold:600` · `--fw-bold:700`.
   Mínimo absoluto 12 px.
3. **Viewport**: `<meta name="viewport" content="width=device-width, initial-scale=1,
   viewport-fit=cover">` y variables `--sat/--sar/--sab/--sal` =
   `env(safe-area-inset-top|right|bottom|left, 0px)`.
4. **Fondo (bug T69)**: `html { background: var(--bg-0); min-height: 100%; }` y
   `body { min-height: 100dvh; background: transparent; }`. El azul pizarra de la
   captura `descubrir_360` (debajo de ~740 px) debe desaparecer.
5. **Base global**: `color-scheme: dark`; `-webkit-tap-highlight-color: transparent`;
   `touch-action: manipulation` en `button, a, [role=button], input`;
   `overscroll-behavior-y: none`; `text-size-adjust: 100%`;
   `:focus-visible { outline: none; box-shadow: var(--ring); }`;
   `@media (hover:none)` sin estilos de hover pegajosos en el reset.
6. **Fondo ambiental barato**: un `body::before` con `position: fixed; inset: 0;
   z-index: -1; pointer-events: none` y dos `radial-gradient` de baja opacidad
   (esmeralda arriba-izquierda, índigo abajo-derecha, usando tokens). Prohibido
   `filter: blur` y `backdrop-filter` para esto.

## Criterios de aceptación
- Computed `font-family` de `body` = Inter y de un título (`h1`) = Outfit. Cero
  peticiones a dominios externos (adjunta el log de red de Playwright).
- Peso de `frontend/dist` antes/después de `npm run build`: el aumento no supera
  **200 KB** (la app va embebida en el `.exe`).
- `descubrir_360` con `fullPage`: el color de un píxel a y=1000 es igual al de y=100
  (ya no hay franja azul). Adjunta la captura.
- Sin desborde horizontal nuevo: `overflowH = 0` en las 9 vistas a 360 px respecto de
  `metricas.json` de T69 (reutiliza `medir_ui.mjs`). Documenta las diferencias de
  texto por el cambio de fuente.
- `npm run check` 0/0, `npm run build` OK, tests `.ts` verdes, `grep wailsjs`
  solo `api.ts`, Go intacto (435).
