# T05 — Referencia de episodio y soporte de películas

> Antes de empezar lee: `AGENTS.md`, `tareas/00_REGLAS.md` y `PROGRESO.md`.
> Usa las **firmas reales** registradas en `PROGRESO.md`, no las del plan.
> Ejecuta SOLO esta tarea. Si necesitas tocar un archivo fuera de "Puedes tocar", detente y repórtalo.

**Depende de:** T03

**Objetivo:** Formatos estables de ID de episodio, definidos antes de instanciar episodios.

**Puedes tocar:** `internal/models/ids.go`, `internal/models/ids_test.go`  *(extensión explícita del paquete de T03)*

**NO debes tocar:** `frontend/**`, `internal/scraper/**`

**Pasos:**
- Formatos: `jkanime:<slug>:episode:<number>`, `jkanime:<slug>:movie`, `jkanime:<slug>:special:<number>`.
- Funciones `NewEpisodeID(provider, slug, kind, number)` y `ParseEpisodeID(id)` (devuelve error en formato inválido).
- Para `Type=movie`, no forzar `Number=1`: el episodio se identifica como `movie`.

**Entregable:** `NewEpisodeID`, `ParseEpisodeID`.

**Comprobación:**
- Tests de tabla: series, película, especial, ID inválido, ida y vuelta Parse(New(x)).
