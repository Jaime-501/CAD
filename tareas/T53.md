## Objetivo
Sustituir el vacío del recuadro rojo (texto "Escribe el nombre de un anime…") por filas horizontales de novedades,
una por sección de cada proveedor. Cada proveedor carga y falla de forma independiente.

## Diseño fijo
**`home.ts`**:
```ts
export const PROVEEDORES_HOME = [{ id: 'jkanime', nombre: 'JKAnime' }, { id: 'animeav1', nombre: 'AnimeAV1' }] as const
export type EstadoProveedor = { estado: 'loading' | 'ok' | 'error'; secciones: models.HomeSection[]; error: string }
export const home: Writable<Record<string, EstadoProveedor>>        // inicializado con 'loading'... solo cuando se pide
export async function cargarProveedor(id: string, noCache = false): Promise<void>   // getHomeSection(id, noCache); error → estado 'error' con mensaje legible
export function cargarTodo(noCache = false): void                    // lanza cargarProveedor de todos EN PARALELO sin await encadenado
```
Se carga **una vez por sesión** al montar `VistaInicio` por primera vez (si el estado ya existe, no se recarga al volver). El botón **"Actualizar"** llama a `cargarTodo(true)`.

**`VistaInicio.svelte`**: título de la página "Novedades"; botón "Actualizar" (deshabilitado mientras algún proveedor cargue); por cada proveedor en el orden de `PROVEEDORES_HOME`, y por cada sección **devuelta**, una `FilaAnimes` con título `"{nombre} · {sección.title}"`. Estados por proveedor:
- `loading`: una fila con 8 *skeletons* (tarjetas grises 140×(140·3/2) px; animación de brillo suave desactivada con `prefers-reduced-motion`).
- `error`: bloque con "No se pudo cargar {nombre}." + botón **"Reintentar"** (`cargarProveedor(id, true)`). El otro proveedor no se ve afectado.
- `ok` con 0 secciones: no se muestra nada de ese proveedor; si **ambos** quedan sin contenido: "Sin novedades por ahora."

**`FilaAnimes.svelte`** (props `titulo: string`, `items: models.Anime[]`, `onAbrir: (a: models.Anime) => void`): contenedor horizontal `overflow-x:auto; scroll-snap-type:x proximity; scrollbar-width:thin`, tarjetas de 140 px de ancho (portada 2:3 `object-fit:cover`, `loading="lazy"`, título a 2 líneas, etiqueta del tipo si existe en `Anime`); botones ‹ › (SVG, `aria-label` "Desplazar a la izquierda/derecha") que desplazan el 80 % del ancho visible con `scrollBy({behavior: reducedMotion ? 'auto' : 'smooth'})`, deshabilitados en los extremos (actualiza con el evento `scroll` y al montar); los botones no se muestran si no hay desbordamiento. Cada tarjeta es un `<button>`; clic → `onAbrir(anime)` usando la **misma función de "abrir anime" de los resultados de búsqueda**.

**`VistaBusqueda.svelte`**: cuando la consulta está vacía y no hay resultados, muestra `<VistaInicio />` en vez del texto actual. Con consulta o resultados, el comportamiento actual no cambia. Al vaciar la consulta se vuelve al Home.
