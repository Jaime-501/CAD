# T11 — Arquitectura de extractores de vídeo

> Antes de empezar lee: `AGENTS.md`, `tareas/00_REGLAS.md` y `PROGRESO.md`.
> Usa las **firmas reales** registradas en `PROGRESO.md`, no las del plan.
> Ejecuta SOLO esta tarea. Si necesitas tocar un archivo fuera de "Puedes tocar", detente y repórtalo.

**Depende de:** T03, T10

**Objetivo:** Evitar depender de una sola regex con extractores en cadena.

**Puedes tocar:** `internal/scraper/jkanime/extractors/extractor.go`, `internal/scraper/jkanime/extractors/extractor_test.go`

**NO debes tocar:** `frontend/**`

**Pasos:**
- Interfaz `VideoExtractor` (`Name()`, `CanHandle(page)`, `Extract(ctx, page)`), recibiendo `httpx.HTTPDoer` por constructor.
- Registro ordenado: JKPlayer, JKPHP, Servers.
- **Política (decisión de diseño):** el resolver ejecuta **todos** los extractores que declaren `CanHandle` y **agrega** las fuentes (no se detiene en el primero). Un extractor que falla se registra en el log y se continúa con el siguiente. Devuelve error solo si el total de fuentes válidas es 0.
- Cada extractor etiqueta sus fuentes con `Server` para permitir fallback de servidor en el reproductor.

**Entregable:** `VideoExtractor`, `Resolver` con `Resolve(ctx, page) ([]models.VideoSource, error)`.

**Comprobación:**
- Tests con HTML artificial: si uno falla se invoca al siguiente; las fuentes de varios extractores se agregan; error si ninguno aporta fuentes.
