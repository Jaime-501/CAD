# T72 — Primitivas de UI e iconos

## Objetivo
Componentes base reutilizables con los tokens, y un set de iconos SVG inline,
para que las tareas de vista no reinventen botones, chips ni insignias.

## Depende de
T70, T71.

## Puedes tocar (archivos NUEVOS en `frontend/src/`)
`Icono.svelte`, `Btn.svelte`, `Chip.svelte`, `Insignia.svelte`, `Esqueleto.svelte`,
`EstadoVista.svelte` (vacío/error/cargando), y `PROGRESO.md`.
Antes de crear cada uno comprueba que el nombre no choca con los existentes
(`Boton*.svelte`, `Tarjeta*.svelte`); si choca, usa otro y repórtalo.

## NO debes tocar
Ningún componente existente (no se migra nada aquí), `*.go`, `wailsjs/**`.

## Especificación
- `Icono`: prop `nombre` (flecha-izq, flecha-der, chevron-izq, chevron-der,
  chevron-abajo, play, pausa, estrella, estrella-llena, marcador, marcador-lleno,
  buscar, brujula, reloj, refrescar, cerrar, papelera, orden-asc, orden-desc,
  historial, pantalla-completa), `tam` (16/20/24), `aria-hidden` por defecto.
  Paths estilo Heroicons (MIT), `stroke="currentColor"`.
- `Btn`: variantes `primario` (`--grad-brand`, texto `--on-brand`, `--sh-glow`),
  `secundario` (superficie + borde), `fantasma`, `icono`. Tamaños `m` y `l`;
  **altura/ancho mínimo 44 px** en todas las variantes. Estados hover (solo con
  `@media (hover:hover)`), `:active`, `:focus-visible`, `disabled`. Prop `href`
  opcional para render como `<a>`. Slot de icono izquierda/derecha.
- `Chip`: `activo` (`--grad-chip-active`, punto indicador) / inactivo
  (`--surface-chip`); envuelve texto sin desbordar; altura táctil ≥ 40 px.
- `Insignia`: tonos `marca|info|alerta|neutro|indigo`, 12 px mínimo, mayúsculas
  opcionales.
- `Esqueleto`: bloque con *shimmer* que se desactiva con `prefers-reduced-motion`.
- `EstadoVista`: variantes `vacio|error|cargando` con icono, título, texto y
  acción opcional.
- Solo tokens: cero colores, radios o sombras literales (verifícalo con grep
  y adjunta el resultado).

(`git status` no debe listarlo).
